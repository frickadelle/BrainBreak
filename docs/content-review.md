## Translation review

Every prompt, option, explanation and unit has a complete German/English pair. Both languages preserve the same numbers, premises, constraints, answer order and correct option ID. Localized punctuation changes only number presentation: `42,195` in German and `42.195` in English represent the same marathon distance. No question uses wordplay or language-dependent knowledge. Pattern questions state their generating rule; deduction questions give sufficient constraints for exactly one listed correct answer. Arithmetic units and numeric targets are positive and independent of language.

The checked proofs cover every arithmetic and logic answer. Primary references support the unit definitions, physical facts, planets, chemical symbols, marathon distance and chessboard definition. NASA states Mercury’s orbital period as 88 Earth days and Jupiter’s as about 4,333 Earth days. Those estimate questions use the published rounded values and identify the rounding in their explanations. The water questions ask for approximate temperatures; their explanations do not claim that modern SI defines Celsius by water’s freezing or boiling point.

Unit tests check package weeks, question counts, unique IDs, valid option IDs, complete English fields, finite numeric targets and the German fallback. A real German/English multiplayer session checks identical question IDs, shared deadlines, score parity, and language changes before and after locking an answer. See [verification](verification.md).

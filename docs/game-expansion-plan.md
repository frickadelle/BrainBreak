# Guided game mix

Implement seven new games: code breaking, visual sets, connections, wavelength, memory, five-letter Wordle and country identification. Preserve all existing categories, server scoring, durable progress and the minimal brain interface. The public frontend starts a six-round mix directly without a category vote. Legacy clients retain the previous vote flow.

Before each guided round, show a bilingual explanation with a harmless example and a Ready button. The server owns a tutorial phase, readiness and a 45-second fallback. All fixed roster players ready starts immediately; missing/offline readiness retains the fallback. A fresh game deadline starts after the tutorial. Never project the real question, solutions, memory sequence or clue target during tutorial. Tutorials repeat because users explicitly requested explanations before every different game.

Shared engine contract lives in `shared/puzzles.ts`. `worker/puzzles.ts` exports `validPuzzleQuestion(question)`, `createPuzzleRound(question, playerIds, roundIndex, startedAt)`, `puzzleView(question, round, playerId, language, now, reveal)`, `applyPuzzleAction(question, round, playerId, action, now)`, `settlePuzzleRound(question, round, now)`, `puzzleEligible(round, playerIds)`, `puzzleDuration(question)`, `puzzleReveal(question, round, playerId, language)`, `puzzleResult(question, round, playerId)`. Invalid actions throw a shared ErrorCode string via an Error carrying `code`, or return no mutation; successful actions persist before acknowledgement. `applyPuzzleAction` returns whether the action changed state. `settlePuzzleRound` supplies the reviewed wavelength clue after 15 seconds, and indicates a due memory preview transition. Result returns `{value, points, success}`. Score max 1,000 per player and no speed bonus. Code, Wordle and connections have 75 seconds; wavelength has 60 seconds; the other games have 45 seconds, with a separate memory preview.

Private multi-attempt progress never appears in another player's view. Code and Wordle feedback handles repeated symbols correctly. Code max 6 attempts; Wordle uses common five-letter English words consistently for every player, with bilingual UI and explicit tutorial copy. Countries lock one answer. Sets lock success or exhausted tries. Connections supports multiple groups, four wrong attempts and partial group points. Memory rejects answers during its preview; progress and deadline survive reload. Wavelength rotates a single captain, keeps their target private, gives guessers a bilingual human clue or a reviewed fallback, and excludes captain from adaptive eligibility. Guess scoring is max(0, 1000 - 40 * absolute distance); a captain earns 1,000 if any guesser earns at least 600. All guesses lock; no answers leak before reveal.

Content: 42 questions per new category, 22 easy / 10 medium / 10 hard. Question IDs must not encode hidden solutions or seeds. Country assets are bundled local flags and verified country outlines; provide primary provenance. No external AI, Google setup or new paid services.

Owners: backend agent owns shared/types.ts, worker/game.ts, worker/room.ts and backend tests. Engine agent owns worker/puzzles.ts and tests/puzzles.test.ts. Content agent owns worker/content/bank-puzzles.ts, worker/content/index.ts, public/countries, content-bank tests and a new content review. Root owns shared/puzzles.ts contract, frontend, tutorial copy, integration/protocol QA, documentation and publication.

Acceptance: all 15 playable games work with two or thirty participants, six distinct games per mix, tutorial readiness and timeout survive reconnect, original rooms remain compatible, new engine attempts/feedback/scoring/privacy are tested, local guided transport sessions reach persisted results, desktop/mobile controls are usable, typecheck/unit/build gates pass, then publish to Cloudflare and push GitHub.
